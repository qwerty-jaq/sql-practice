# SQL Practice

SQL Server scripts from my database modules at Eduvos.

## What's inside

- Creating databases and tables (e.g. `FluffyBakes_DB` with Customers, Products, Orders and OrderDetails)
- Primary and foreign keys between related tables
- Inserting and querying data

## How to run

1. Open a `.sql` file in **SQL Server Management Studio (SSMS)**
2. Connect to your local SQL Server
3. Press **Execute** (F5)
